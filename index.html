      🛡️ このページが安全な理由

      1. 🔐 パスワードは当アプリを一切通りません

        ログインは Spotify 公式ドメイン（accounts.spotify.com）の画面で直接行われます。 当アプリは業界標準の OAuth 2.0 PKCE 方式を使っており、あなたのパスワードを見ることも保存することもできません。

      2. 💾 データはあなたの端末の中だけに保存されます

        取得したアクセストークン・Client ID・アニメ情報キャッシュは、お使いのブラウザ内（localStorage）にのみ保存されます。 当アプリには独自のサーバーが存在せず、外部サーバーへ送信されることは一切ありません。 （通信先は Spotify API と、公開データベース AnimeThemes / Wikipedia / LRCLIB への曲名検索のみです）

      3. 🎚️ 要求する権限は最小限です

        要求するのは「プレイリストの閲覧」と「再生状態の取得・再生制御」のみです。 プレイリストの編集・削除、フォロー操作、個人情報（メールアドレス等）へのアクセス権は要求しません。

        • playlist-read-private 非公開プレイリストの閲覧
        • playlist-read-collaborative 共同プレイリストの閲覧
        • user-read-playback-state 再生状態の取得
        • user-modify-playback-state 再生・一時停止・シーク等の操作
        • user-read-currently-playing 再生中の曲の取得
      4. 📖 ソースコードはすべて公開されています

        本アプリは HTML / CSS / JavaScript のみで作られており、GitHub 上で全ソースコードを誰でも閲覧・検証できます。 ブラウザの開発者ツールで実際の通信内容を確認することも可能です。

      連携を解除したい場合は、Spotifyの「アプリの管理」からいつでもアクセス権を取り消せます。
